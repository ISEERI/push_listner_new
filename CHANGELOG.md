## [1.0.0] - 2026-01-23

### Добавлено

#### Основная функциональность
- **DLMS Push Listener** — сервер для приёма DLMS/COSEM push-сообщений от счётчиков электроэнергии
- **Поддержка нескольких протоколов** — TCP и UDP серверы с возможностью запуска на нескольких портах одновременно
- **Автоматическая генерация ответов** — автоматическая генерация HDLC-подтверждений с корректным FCS и временной меткой (UTC+3)

#### Обработка сообщений
- **Парсинг стандартных DLMS push** — обработка сообщений с OBIS-кодами
- **Поддержка нового формата schedule push** — распознавание и парсинг профилей с логическим именем
- **Обработка autoconnect-сообщений** — обработка текстовых сообщений формата `<sn=... ip=... pt=...>`
- **Надёжная обработка ошибок** — игнорирование некорректных пакетов без остановки сервера

#### Сохранение данных
- **Ежедневные JSON-файлы** — автоматическое сохранение данных в файлы по дням:
  - `dlms_push_ГГГГ-ММ-ДД.json` — стандартные пуши
  - `dlms_day_push_ГГГГ-ММ-ДД.json` — пуши профилей по расписанию
  - `autoconnect_ГГГГ-ММ-ДД.json` — сообщения автоконнектов
- **Текстовые лог-файлы** — сохранение сырых логов в `dlms_log_ГГГГ-ММ-ДД.txt`
- **Настраиваемые директории** — отдельные папки для сохранения и загрузки данных
- **Постоянная конфигурация** — пути сохраняются между запусками в `config.json`

#### Анализ и визуализация
- **Три режима анализа** во встроенном просмотрщике:
  - Стандартные пуши (OBIS-коды и значения)
  - Пуши профилей (логическое имя, тип профиля, валидация периодичности)
  - Автоконнекты (список подключений по SN, IP, порту)
- **Анализ автоконнектов** — иерархическое отображение, сгруппированное по серийным номерам
- **Валидация интервалов**:
  - Валидация профилей: суточные (24ч) vs получасовые (30мин) интервалы
  - Валидация автоконнектов: 12 часов ± 1 минута между подключениями
- **Фильтрация по SN** — поиск и фильтрация по серийному номеру в анализе автоконнектов
- **Умная сортировка колонок** — интеллектуальное определение типа данных (даты, числа, IP-адреса)

#### Пользовательский интерфейс
- **Двухвкладочный интерфейс** — вкладки "Сервер" и "Анализ"
- **Цветовая кодировка логов**:
  - 🟢 Зелёный: комментарии OBIS (`<!-- ... -->`)
  - 🟡 Жёлтый: отладочные сообщения (`[✓]`)
  - 🟠 Оранжевый: успешное сохранение (`[+]`)
  - 🔵 Синий: autoconnect-сообщения
  - 🔴 Красный: ошибки
- **Функция копирования** — контекстное меню и горячие клавиши (Ctrl+C на англ. расскалдке) для копирования строк
- **Экспорт в Excel** — экспорт в Excel с автоматической подстройкой ширины колонок
- **Выбор директорий** — диалоговые окна для выбора папок сохранения/загрузки

#### Технические особенности
- **Интеграция gurux-dlms v1.0.195**
- **Поддержка HDLC-фреймов** с LLC-заголовками
- **Обработка часовых поясов** — корректное преобразование UTC+3 (значение `FF4C` = -180 минут)
- **Обработка hex-данных** — автоматическое преобразование в человекочитаемые форматы
- **Вложенные структуры** — поддержка сложных структур данных DLMS и массивов


### Требования
- Python 3.8+
- Зависимости: `tkinter`, `gurux-dlms`, `openpyxl`, `tkcalendar`

### Примечания
- **Портативное приложение** — не требует установки, запускается из исходников
- **Настраиваемые пути** — все директории настраиваются через UI
- **Работа в фоне** — сервер продолжает работать при переключении вкладок

> **Планируемые функции следующей версии:** улучшение интерфейса, добовление нового функционала при необходимости, исправление багов при их обнаружении
